Correctness
verified, not assumed

    
The public behaviour is pinned by differential vectors: the same fixed inputs are
      evaluated two independent ways, and the values are replayed against the library. Each family is
      covered, so a regression anywhere turns a check red.

Using it

      


// add to your moon.mod import block
import {
  "moonbitstack/moonstl@0.1.0",
}

// one import names the whole module
let m : @map.IndexMap[String, Int32] = @map.IndexMap::new()
let _ = m.set("a", 1)
let _ = m.set("b", 2)
@map.IndexMap::new()   // the module root re-exports the families


// a few families side by side
let cache : @cache.LruCache[String, Int32] = @cache.LruCache::new(capacity=8)
let _ = cache.set("k", 42)
@cache.LruCache::new()

let h : @heap.DaryHeap[Int32] = @heap.DaryHeap::default()
let _ = h.push(3)
let _ = h.push(1)
h.peek()   // Some(1)

let s : @sketch.CountMinSketch[String] = @sketch.CountMinSketch::new(
  epsilon=0.01,
  confidence=0.99,
)
let _ = s.insert("hello")
s.estimate("hello")   // >= 1
