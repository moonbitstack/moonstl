Ten packages of data structures and algorithms for MoonBit — indexed maps, priority queues, range trees, eviction policies, sketches, string search, perfect hashing. Each one ships with reference vectors computed twice, by two other standard libraries, so the answers are checked against something that is not itself.

Every panel below runs the real library, compiled to WebAssembly and instantiated in this tab. Nothing here is a re-implementation for the demo.

      03
How it is checked

      differential · mutation · replay
    


    

      

        
2refs

        
Answers computed twice

        
Each package's vectors are produced independently by the Python standard library and by Rust's,
          then diffed byte for byte. Two mature implementations have to agree before a number is committed.

      

      

        
18breaks

        
Mutation tested

        
Two key lines per package were broken on purpose — comparisons, bounds, renumbering, expiry
          boundaries — and every break turned the suite red before it was reverted.

      

      

        
4backends

        
Same tests everywhere

        
Wasm, wasm-gc, JavaScript and native run the identical suite, so a structure that passes on one
          target is not allowed to drift on another.
