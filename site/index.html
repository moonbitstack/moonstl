PLATE IV

      
The Assay

      
Differential · mutation · replay

    


    

      

        
2refs

        
Answers computed twice

        
Each family's reference values are produced independently by the Python standard library
          and by Rust's, then compared byte for byte. Nothing is committed until both agree.

      

      

        
18breaks

        
Mutation tested

        
Two key lines per family were broken deliberately — comparisons, bounds, renumbering,
          expiry — and each break turned the suite red before it was reverted.

      

      

        
4backends

        
The same tests everywhere

        
Wasm, wasm-gc, JavaScript and native run the identical suite, so no structure is allowed
          to drift on one target and pass on another.

          II
          
Import a family

            
Packages are separate: bring in map, heap, tree,
              cache, sketch, seq, text,
              phf, algo or spec — and nothing else follows.

Wasm, wasm-gc, JavaScript and native. Capacities and orderings are explicit arguments,
              and fallible constructors raise rather than abort.
